# Access Gate Shared Study Roadmaps by Source Scope

For the MVP, ClassVault keeps saved study roadmaps private by default and allows owners to explicitly enable or revoke read-only share links, including links for previously generated Pro roadmaps after the owner downgrades. When sharing is enabled, the link's visible content follows the roadmap's source scopes: public-note content can be viewed by anyone with the link, while university-derived sources and derived roadmap sections are visible only to viewers who are authenticated active members of the relevant university community; each major section records its source note IDs, and shared rendering hides the entire section if any source note for that section is inaccessible to the viewer. Owner progress remains private and viewers cannot copy the roadmap.
