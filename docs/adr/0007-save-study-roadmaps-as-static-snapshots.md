# Save Study Roadmaps as Static Snapshots

For the MVP, ClassVault saves each study roadmap as a static snapshot generated at that moment, rather than automatically updating it when source notes change, are edited, deleted, or when the student's plan later downgrades. Major roadmap sections retain their source note references so shared views can enforce source-scope access later, trading freshness and entitlement re-evaluation for stable progress tracking, predictable source references, and a plan that does not shift underneath the student after they begin using it.
